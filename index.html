5. Imágenes

Imagen informativa con <figure> y <figcaption>

Imagen responsive con <picture> y srcset

El elemento <picture> permite servir imágenes distintas según el tamaño del viewport o las capacidades del navegador: 

<picture>
  <source media="(min-width: 800px)"
          srcset="imagen-grande.webp" type="image/webp" />
  <source media="(min-width: 800px)"
          srcset="imagen-grande.jpg" />
  <img src="imagen-pequena.jpg"
       alt="Descripción de la imagen"
       width="400" height="300"
       loading="lazy" />
</picture>

6. Elementos multimedia

Audio (<audio>)

El elemento <audio> permite incrustar sonido sin plugins. Se proporcionan múltiples formatos para compatibilidad entre navegadores: 

<audio controls preload="metadata">
  <source src="audio/ejemplo.ogg" type="audio/ogg" />
  <source src="audio/ejemplo.mp3" type="audio/mpeg" />
  <p>Tu navegador no admite audio HTML5.
     <a href="audio/ejemplo.mp3">Descarga el archivo.</a></p>
</audio>

Vídeo (<video>)

El elemento <video> incrusta vídeo con controles nativos del navegador. El atributo poster muestra una imagen de previsualización antes de la reproducción: 

<video controls width="640" height="360"
       poster="miniatura.jpg" preload="metadata">
  <source src="video/ejemplo.webm" type="video/webm" />
  <source src="video/ejemplo.mp4"  type="video/mp4" />
  <track kind="subtitles" src="subtitulos.vtt"
         srclang="es" label="Español" default />
  <p>Tu navegador no admite vídeo HTML5.
     <a href="video/ejemplo.mp4">Descarga el vídeo.</a></p>
</video>

El elemento <track> dentro de <video> añade subtítulos o descripciones en formato WebVTT, mejorando la accesibilidad para personas con discapacidad auditiva.
