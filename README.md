# UT2 · Actividad 2 – Etiquetas y atributos comunes en HTML5

Página didáctica sobre las etiquetas y atributos más usados de HTML5, con ejemplos de cada uno. Segunda actividad de la Unidad 2 del módulo «Lenguajes de Marcas y Sistemas de Gestión de Información» (1º DAW).

**Ver online:** https://serberar.github.io/ut2_2/

## Contenido

- Etiquetas semánticas (`header`, `nav`, `main`, `section`, `article`, `footer`).
- Atributos globales y específicos más habituales.
- Buenas prácticas de accesibilidad, como el enlace «saltar al contenido» visible al navegar con teclado.

## Tecnologías

HTML5 y CSS3 (variables CSS), en un único archivo sin dependencias.

## Cómo verlo

Abre `index.html` en el navegador o entra en la versión publicada en GitHub Pages.
